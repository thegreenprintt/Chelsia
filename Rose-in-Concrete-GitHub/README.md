# Rose in Concrete — Website

Breaking Chains. Building Futures. Long live the rose that grew from concrete.

A single-page website for the Rose in Concrete mentorship initiative.

## Files
- `index.html` — the website
- `assets/` — logo and photos
- `.nojekyll` — tells GitHub Pages to serve the `assets/` folder as-is

## Deploy free with GitHub Pages
1. Create a new repository on GitHub (e.g. `rose-in-concrete`).
2. Upload **all** of these files, keeping `index.html` at the top level and the `assets` folder next to it.
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
5. Wait ~1 minute. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Connecting a custom domain (e.g. roseinconcrete.org)
In **Settings → Pages → Custom domain**, enter your domain and follow the DNS steps your registrar provides.

## Editing
- Text and links: open `index.html` in any editor and search for the words you want to change.
- Photos: replace the files inside `assets/` (keep the same filenames), or update the `src="assets/..."` paths.
- Forms: the "Refer a Youth" and "Become a Mentor" buttons link to your JotForm forms — search `jotform.com` in `index.html` to update them.
